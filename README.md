# Soundpad
Sistema de Chamadas para Caixa e Atendimento

Aplicação desktop desenvolvida em Python para organização de filas e chamado de senhas/guichês em ambientes comerciais. O sistema opera em arquitetura cliente-servidor na rede local, permitindo que múltiplos terminais (caixas) enviem solicitações remotamente via endereço IP para uma tela principal de exibição.
